# CI-NEB and IDM

Apply this when the project actually needs a reaction path or transition state. It covers **CI-NEB** with optional IDM recovery; record the project's chosen path method in `WORKFLOW.md`.

## CI-NEB

- Name directories by reaction step, not by an isolated intermediate. Record the balanced transformation, source and calculation settings of both endpoints, atom identity/order correspondence, and why this step needs a path. Check that both endpoints and every image use the same fixed lattice vectors, atom count, species and order before interpolation or submission; endpoints relaxed in different cells need a valid common-cell preparation. Do not assume every adjacent adsorption intermediate is directly compatible.
- Inspect the interpolated path and first actual CI-NEB inputs at the first-input review in `SKILL.md`. Subsequent reviewed-route paths continue autonomously unless forces, image geometry or energy profile are anomalous.
- Match the requested resources to the INCAR `IMAGES` count (the moving images, not the two endpoints): total MPI ranks must divide evenly across those images, and each image's ranks must be compatible with the selected `NCORE`. Preserve the site's reviewed script conventions.
- When progress stalls, use current image structures, force/energy trends and SCF evidence to decide whether interpolation, image spacing, input accuracy or a method change addresses the problem. Do not prescribe a fixed number of extra CI-NEB steps/images or blindly restart. A usable image already near the saddle can seed IDM directly.

## Optional IDM recovery

IDM is a response to a difficult CI-NEB, not an automatic extra stage after a normally completed path. IDM is a new calculation type under `SKILL.md`: review the first actual IDM input and its chosen unstable direction before submission. Later same-route IDM attempts proceed within the reviewed scope unless anomalous.

1. Select a plausible near-saddle structure from the existing CI-NEB evidence. An invalid, runaway or wrong-reaction image is not an IDM seed.
2. Obtain a trial unstable direction with a **direction-finding frequency** calculation. Use the project's finite-difference settings (`IBRION=5` with chosen `POTIM` and `NFREE`; see the [example default](example-default.md) for one set). An adsorbate-only free-atom set is suitable for an adsorbate-only rearrangement; include surface atoms directly involved in the reaction when necessary. This calculation prepares IDM and is distinct from optional final frequency validation. A Gamma `1×1×1` calculation may be a cheap direction guess; if its mode is ambiguous or the path used a different k mesh, assess the mode on the path's actual energy surface.
3. Inspect each imaginary mode's displacement against the intended CI-NEB reaction direction. Do not select the numerically largest imaginary frequency without that check. No imaginary mode in a partial Hessian proves only that no negative mode was found in the selected free coordinates; it does not prove the full structure is a minimum.
4. Build the IDM POSCAR from the selected source geometry with the original method's intended selective-dynamics flags, not the extra frequency-only freezes. Preserve atom order, lattice, coordinates and species/POTCAR identity; append one Cartesian dimer-axis vector per atom after a separating blank line. If a helper rewrites the POSCAR, verify those invariants and the vector length before submission. Keep originals and write new outputs to the IDM attempt directory.
5. Build IDM inputs from the reviewed CI-NEB/final calculation template, not by inheriting the frequency INCAR wholesale. Set `IBRION=44` and a project-appropriate `EDIFFG`; do not use lattice optimization (`ISIF>2` is unsupported for IDM). Restore the actual k mesh and matching executable (which may still be Gamma). Do not treat a copied `POTIM=0.05`, `NSW=500` or `EDIFF=1E-5` as universal IDM policy. The documented IDM movement controls are `STEP_SIZE` and `STEP_MAX`; alter them only for an observed reason.
6. If the CI-NEB image is already a good seed, proceed directly at target settings. Use a bounded coarse IDM only when needed to localize a difficult saddle, then reconverge at the common final energy settings. A coarse energy is not a reportable barrier. Check electronic/force convergence, intended geometry and dimer curvature; negative curvature alone is insufficient. Report explicitly whether the whole CI-NEB path converged or only an IDM transition state was obtained. Evaluate a barrier only against endpoints under comparable energy-affecting settings.

Standalone frequency validation after CI-NEB/IDM runs only for paths the researcher selects. If requested, interpret significant imaginary modes and their directions within the actually displaced degrees of freedom; the adsorbate-only Hessian cannot exclude surface-coupled modes.

Choose frequency k points by demonstrated accuracy and cost; do not automatically densify the mesh merely because this is a frequency task. Freezing slab atoms reduces the displacements, not the electronic sampling needed for the whole system. For large adsorption supercells, consider Gamma `1×1×1` with `vasp_gam`. Compare one representative case against the reviewed formal mesh: check important frequencies, ZPE and significant imaginary-mode counts/directions at the project's required accuracy. Record the supported family and chosen setting in `WORKFLOW.md`, then reuse the sufficient cheaper mesh for similar cases instead of running paired checks for every intermediate. For formal validation without evidence supporting reduced sampling, retain the final relaxation mesh. Small cells, k-sensitive metallic surfaces or suspect imaginary/soft modes warrant a denser-mesh check with `vasp_std`, keeping the other relevant electronic settings consistent.
