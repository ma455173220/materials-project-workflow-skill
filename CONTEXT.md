# Research calculation workflow / 科研计算工作流

This glossary keeps planning, permission and result judgments distinct across projects.
本词汇表区分规划、运行许可和结果判断，供不同课题共用。

## Language / 术语

**Scientific goal / 科研目标**: The property, comparison or mechanism the researcher wants to determine. It does not prescribe a software package or stage list. / 研究者想确定的性质、比较或机理；它本身不指定软件或阶段。

**Proposed route / 候选路线**: A reasoned sequence of calculations suggested to answer the goal, before the researcher chooses it. / 为回答目标而建议、尚未被研究者选定的计算路线。

**Selected route / 已选路线**: The calculation stages and comparison principles chosen by the researcher for a defined scope. It is not by itself permission to submit a job. / 研究者为明确范围选定的阶段和比较原则；它本身不是作业提交许可。

**Reviewed execution scope / 已审核执行范围**: The actual first input package and bounded follow-on work the researcher has reviewed for autonomous submission and recovery. / 研究者审核过的首份实际输入，以及获准自主提交和故障处理的后续工作范围。

**Scientific acceptance / 科学接受**: A judgment that a completed result is suitable for a stated scientific use; scheduler completion alone does not establish it. / 认定完成结果可用于指定科研目的的判断；调度器显示完成并不等于科学接受。

**Routine recovery / 常规修复**: An attempt-specific change to reach the selected route's scientific target without changing its physical model or final comparison protocol. / 为达到已选路线的科研目标而对某次尝试作出的调整，不改变物理模型或最终可比协议。

**Final comparison protocol / 最终可比协议**: The shared method, settings and energy definition under which selected endpoints may be compared. / 用于比较所选终点的共同方法、设置和能量定义。

**Final choice / 最终采用结果**: The structure and result chosen from one stage's candidate calculations to feed its next stage, together with the source run and selection reason; it need not be the lowest raw energy or a final scientific claim. / 从某阶段多个候选计算中选出、交给下一阶段的结构与结果，连同原运行目录和选择理由；它未必是原始能量最低者，也不自动构成最终科学结论。
_Avoid_: best / 最优
